3. Buka upload GitHub

Di GitHub, login dengan akunmu, pilih file hasil unduhan bernama foto.img.jpeg untuk menggantikan foto lama, lalu klik Commit changes. Tunggu GitHub Pages selesai memperbarui website, kemudian muat ulang halaman.

Pastikan nama file tetap foto.img.jpeg, bukan foto.img (1).jpeg, dan foldernya sama dengan index.html. Jika branch dilindungi, perubahan perlu disetujui melalui pull request.
